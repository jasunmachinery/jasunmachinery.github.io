Процесс производства мыла из растительных масел/животных жиров и каустической соды

Весь процесс разделен на два основных этапа.

Первый этап (Часть А) — это система омыления и сушки для получения мыльных нитей. Это реакция омыления растительных масел/животных жиров и каустической соды для образования мыльной основы. Затем эта мыльная основа обрабатывается в вакуумной сушильной системе и грануляторе, который экструдирует ее в мыльные нити.

Второй этап (Часть В) — это производство готового мыла из мыльных нитей. Мыльные нити помещаются в мыломешалку, которая смешивает их с ароматизатором и пигментом. Затем смесь подается в рафинировочную мельницу (рафинер). Ее основная задача — тщательно перемешать, гомогенизировать и измельчить мыльные материалы. После этого мыльные нити поступают в трехвалковую мельницу (трехвалковый измельчитель), где они измельчаются в тонкие мыльные листы. Эти тонкие листы по конвейерной ленте подаются в двухшнековый вакуумный пресс для мыла или одношнековый пресс для мыла (экструдер для мыла), где они снова измельчаются и непрерывно экструдируются в длинный брусок мыла желаемой формы. Затем длинный брусок разрезается и формируется в отдельные бруски мыла необходимого размера с помощью автоматического станка для резки мыла (резак для мыла) или штамповочного станка для мыла (штамповочный станок/принтер для мыла/пресс для мыла/машина для перфорации мыла). Наконец, готовые бруски мыла упаковываются в упаковочную машину (машина для упаковки мыла в картонные коробки/машина для упаковки мыла v бумагу).

Для большинства начинающих производителей мыла без опыта и с небольшим бюджетом мы рекомендуем выбрать вариант B для начального производства.
